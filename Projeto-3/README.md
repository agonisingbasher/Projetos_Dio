# 💻 Desafio DIO - Resolvendo Códigos em Python com Copilot

Bem-vindo ao meu repositório do desafio da Digital Innovation One (DIO)! Este projeto documenta minha prática na resolução de algoritmos em Python, explorando o uso de Inteligência Artificial (GitHub Copilot) para acelerar o desenvolvimento e melhorar a produtividade.

## 📂 Organização do Repositório

O repositório foi dividido em pastas para organizar cada etapa do desafio:

- 📁 `Dados/` - Algoritmo de Concatenação de Dados
- 📁 `loop/` - Algoritmo de Repetição de Textos
- 📁 `Matematica/` - Algoritmo de Operações Matemáticas Simples

## 🚀 Tecnologias Utilizadas

- **Python 3** (Lógica de Programação, Manipulação de Strings e Operadores Matemáticos)
- **GitHub Copilot / IA** (Auxílio na estruturação e eficiência do código)
- **Markdown** (Documentação do projeto)

---

## 📌 Sobre o Desafio

O objetivo principal desta atividade foi recriar soluções de algoritmos básicos em Python aplicando os conceitos aprendidos durante as aulas, documentando o raciocínio técnico de forma clara e utilizando o GitHub como plataforma de versionamento.
