## 📝 Descrição
Este script funciona como uma calculadora básica. Ele solicita dois números ao usuário e permite escolher qual operação matemática simples será realizada entre eles.

## 🚀 Como funciona
1. O usuário insere o primeiro número.
2. O usuário insere o segundo número.
3. O usuário escolhe a operação desejada: Adição (`+`), Subtração (`-`), Multiplicação (`*`) ou Divisão (`/`).
4. O sistema utiliza estruturas de decisão (`if/elif/else`) para calcular e exibir o resultado, incluindo uma validação para evitar divisão por zero.

**Arquivo principal:** `matematica.py`
