## 📝 Descrição
Este algoritmo foi desenvolvido para receber duas informações diferentes fornecidas pelo usuário e concatená-las (juntá-las) em uma única string, exibindo o resultado final.

## 🚀 Como funciona
1. O programa solicita a primeira entrada de dados.
2. Em seguida, solicita a segunda entrada.
3. Utiliza o operador de adição (`+`) para unir as duas strings com um espaço entre elas.
4. Imprime o resultado na tela.

**Arquivo principal:** `concatenacao.py`
