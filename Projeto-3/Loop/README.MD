## 📝 Descrição
Este algoritmo recebe uma string (texto) e um número inteiro como entrada do usuário. O objetivo é retornar a string repetida a quantidade de vezes informada pelo número.

## 🚀 Como funciona
1. O programa pede ao usuário que digite uma palavra ou texto.
2. Pede um número inteiro que servirá como multiplicador.
3. Utiliza a característica do Python de multiplicar strings (`texto * numero`) para criar o loop de repetição.
4. Exibe o texto repetido na tela.

**Arquivo principal:** `repeticao.py`
