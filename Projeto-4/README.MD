# 🚀 Projeto 4 - Explorando Features do GitHub

Bem-vindo ao **Projeto 4**! Este repositório foi criado para demonstrar o domínio sobre as ferramentas avançadas do GitHub, incluindo a criação de Wikis, gestão de Issues, abertura de Pull Requests e organização via GitHub Projects.

## 📝 Sobre o Projeto

Este repositório contém três miniprojetos desenvolvidos em Python que servem como base para testar as funcionalidades de gerenciamento e documentação do GitHub:
1. **Gerador de Senhas** (`gerador_senhas.py`)
2. **Conversor de Temperatura** (`conversor_medidas.py`)
3. **Jogo de Adivinhação** (`jogo_adivinhacao.py`)

## 🛠️ Funcionalidades do GitHub Utilizadas

- **Wiki:** Documentação técnica completa dos scripts.
- **Issues:** Rastreamento de bugs e novas funcionalidades.
- **Pull Requests (PR):** Revisão de código estruturada.
- **Projects (Kanban):** Organização das tarefas (To Do, In Progress, Done).

Consulte a aba **Wiki** deste repositório para ver a documentação detalhada de cada script!
