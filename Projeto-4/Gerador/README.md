## 📝 Descrição
Um utilitário simples em Python focado em segurança da informação. Este script gera senhas aleatórias e robustas combinando letras maiúsculas, minúsculas, números e caracteres de pontuação.

## 🚀 Como funciona
1. O usuário executa o script e define o tamanho desejado para a senha (ex: 12 ou 16 caracteres).
2. O sistema utiliza a biblioteca `string` para mapear todos os caracteres disponíveis e a biblioteca `random` para selecionar aleatoriamente.
3. O laço de repetição constrói a string final com base no tamanho informado e a exibe no terminal.

**Arquivo principal:** `gerador_senhas.py`
