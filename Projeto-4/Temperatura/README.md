## 📝 Descrição
Um script matemático básico que automatiza a conversão de temperaturas da escala Celsius para a escala Fahrenheit, formatando a saída para fácil leitura.

## 🚀 Como funciona
1. O programa solicita que o usuário insira um valor de temperatura em graus Celsius (aceita números decimais).
2. O valor é passado para uma função específica que aplica a fórmula padrão de conversão: `(C * 9/5) + 32`.
3. O resultado é exibido no terminal formatado com exatamente duas casas decimais para precisão.

**Arquivo principal:** `conversor_medidas.py`
