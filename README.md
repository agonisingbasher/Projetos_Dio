### 🌐 Tech Blog — Projeto de Revisão de HTML (Projeto 1)

Este projeto é um exercício prático para revisar e reforçar conhecimentos básicos de HTML. Foi criado para demonstrar entendimento das estruturas fundamentais de páginas web, boas práticas simples de marcação e capacidade de entregar um pequeno projeto funcional.

- **Objetivos:**
  - Revisar conceitos básicos de HTML (estrutura, links, listas, âncoras, inclusão de CSS e imagens).
  - Demonstrar organização, atenção e determinação — mesmo em tarefas simples — buscando sempre o aperfeiçoamento.
- **Plataforma de Aprendizado:** [Dio.me](https://dio.me)
- **Notas:** Este projeto não é um produto final, mas sim um portfólio e um exercício para praticar e mostrar conhecimentos fundamentais. Sugestões de melhorias visuais ou ideias para transformar em um pequeno site dinâmico no futuro são muito bem-vindas!

### 🎵 Copiloto de Vendas com IA - Instrumentos Musicais (Projeto 2)
<p align="left">
  <img src="https://img.shields.io/badge/IA-Copilot-purple?style=flat-square&logo=openai" alt="AI">
  <img src="https://img.shields.io/badge/Varejo-Música-yellow?style=flat-square&logo=music" alt="Música">
</p>

Uma adaptação do desafio de Copiloto de Vendas para o mercado de Instrumentos Musicais e Áudio Profissional. A solução atua como um assistente inteligente para vendedores e atendentes de uma loja de música.

- **Funcionalidades da IA:**
  - **Recomendação:** Sugere o instrumento ideal com base no nível de habilidade e preferências musicais do cliente.
  - **Suporte Técnico:** Fornece respostas rápidas e técnicas sobre especificações (madeiras, captação, encordoamento).
  - **Negociação:** Contorna objeções de preço sugerindo sempre o melhor custo-benefício.
- **Estrutura do Projeto:**
  - `AGENTS.md`: Definição dos perfis dos agentes de IA (Luthier, Especialista de Áudio, Vendedor).
  - `CLAUDE.md`: System prompts de exemplo para configurar o comportamento do LLM.
  - `knowledge/`: Base de conhecimento contendo guias técnicos e argumentos de vendas.
