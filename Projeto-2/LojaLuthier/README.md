# Copiloto de Vendas com IA - Instrumentos Musicais

Este projeto é uma adaptação do desafio de Copiloto de Vendas para o mercado de Instrumentos Musicais e Áudio Profissional. 

## Visão Geral
A solução atua como um assistente para vendedores e atendentes de uma loja de música, ajudando a:
- Recomendar o instrumento ideal com base no nível de habilidade e preferências musicais do cliente.
- Fornecer respostas rápidas e técnicas sobre especificações (madeiras, captação, encordoamento).
- Contornar objeções de preço sugerindo o melhor custo-benefício.

## Estrutura do Repositório
- `AGENTS.md`: Definição dos perfis dos agentes de IA (Luthier, Especialista de Áudio, Vendedor).
- `CLAUDE.md`: System prompts de exemplo para configurar o comportamento do LLM.
- `knowledge/`: Base de conhecimento contendo guias técnicos e argumentos de vendas.
